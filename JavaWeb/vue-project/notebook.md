# Vue 3 项目创建与运行指南 (Mac 版)

---

## 一、 创建项目

在终端（Terminal）或 VS Code 终端中执行以下步骤：

### 1. 初始化项目

进入你存放代码的目录，执行：

```bash
npm create vue@latest
```

### 2. 配置选项建议

执行上述命令后，根据提示进行选择。对于 Java 后端背景的学习者，建议配置如下：

| 配置项          | 建议选择   | 理由                                     |
| --------------- | ---------- | ---------------------------------------- |
| Project name    | 你的项目名 | 例如：`vue-study-demo`                   |
| Add TypeScript? | **Yes**    | 强类型检查，更接近 Java 开发体验         |
| Add Vue Router? | **Yes**    | 必选，用于单页面应用的路由跳转           |
| Add Pinia?      | **Yes**    | 必选，用于状态管理（类似后端的全局缓存） |
| Add ESLint?     | **Yes**    | 语法检查，预防低级错误                   |
| Add Prettier?   | **Yes**    | 自动格式化代码，保持代码整洁             |

---

## 二、 运行项目

项目创建完成后，按照以下指令进入目录并启动：

### 1. 进入项目文件夹

```bash
cd 你的项目名

```

### 2. 安装依赖 (只需执行一次)

```bash
npm install
```

> **提示**：这会生成 `node_modules` 文件夹，存放项目运行所需的全部库文件。

### 3. 启动开发服务器

```bash
npm run dev
```

### 4. 访问页面

在浏览器中输入终端显示的地址，通常是：
`http://localhost:5173/`
